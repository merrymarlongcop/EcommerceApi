# Ecommerce API Project

## 📌 Project Overview
This is a simple RESTful API built using Spring Boot, designed to manage product information for an e-commerce system. It supports basic operations such as creating, reading, updating, and deleting products, along with input validation, proper error handling, and appropriate HTTP status codes. The application uses in-memory storage, meaning all data will be reset when the application is restarted.
